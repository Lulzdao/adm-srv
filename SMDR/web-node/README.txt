ОБНОВЛЕНИЕ (поверх уже установленной версии)
==============================================

1. Остановите сервер (Ctrl+C в окне, где запущен npm start).

2. Распакуйте архив ПОВЕРХ существующей папки C:\SMDR\web-node\
   (согласитесь на замену файлов).

3. Никаких новых npm-пакетов в этот раз не добавлялось — 
   npm install заново запускать не обязательно, но если хотите
   на всякий случай — не помешает:
   cd C:\SMDR\web-node
   npm install

4. npm start

5. Откройте http://localhost:5001 — что нового:
   - Кнопка 🌙/☀️ в шапке — переключение тёмной/светлой темы,
     выбор запоминается в браузере.
   - Шрифты и отступы увеличены.
   - Кнопка "Сброс" рядом с "Фильтр" — сбрасывает все фильтры.
   - Колонки в журнале переставлены:
     Дата, Время, Добавочный, Направление, Детали, Длительность,
     Ожидание, Сотрудник, Линия.

ВАЖНО: схема базы (smdr.db) не менялась — удалять базу не нужно.
